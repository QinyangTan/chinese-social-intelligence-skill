# Source Corpus

This file defines the source layer for the guide library. A source is **not** a command. Each source is converted into modern, scoped, executable guidance and then filtered by law, safety, equality, consent, privacy, professional ethics, and the user's explicit context.

## How to read source labels

- **PD-classic**: pre-modern source; only short source cues are used and all operational language is newly written.
- **Modern-book / academic**: copyrighted scholarship; this repository stores bibliographic facts and original concept-level summaries, not reproduced chapters or passages.
- **Official-public**: public policy / curriculum context; operational rules are original synthesis.
- **General-communication**: non-China-specific theory used only as a secondary lens.

## Source-to-guide rule

Every guide should make a distinction among:

1. **descriptive observation** — a pattern found in scholarship;
2. **normative recommendation** — what the agent should do now;
3. **modern guardrail** — when the inherited or observed pattern should *not* be followed.

For example, scholarship may describe gift exchange as creating obligation. The operational rule is **not** “create obligation with gifts.” It is “recognize that gifts can create perceived obligation; avoid coercion, conflicts of interest and quid-pro-quo exchange.”

## Copyright rule

Modern books and academic works remain copyrighted. The repository must not copy their prose, chapter summaries at substitutive length, tables, or long excerpts. It may:

- cite bibliographic facts;
- identify high-level concepts;
- write original, compact operational syntheses;
- use short quotations only when legally appropriate and necessary.
